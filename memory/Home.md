# SakhiLine — Shared Memory

Shared memory for **Shanky** (backend) and **Johny** (platform/UI/speech). Lives in git (`memory/`) so it's shared by both of us; open this folder as an Obsidian vault.

**Deadline:** Gnani AI contest closes **2026-11-10 23:59 IST**.

## Map
- [[Project Overview]] — what we're building and the hard rules
- [[Ownership and Seams]] — who owns which files, the interfaces between lanes
- [[Shanky Lane]] — backend phases 0–8 (done)
- [[Johny Roadmap]] — Johny's phases J0–J8 (current work)
- [[Decisions and Open Questions]]

## How to update
1. When you start or finish a phase, tick it in [[Johny Roadmap]] (or [[Shanky Lane]]).
2. Add a dated entry at the top of [[Progress Log]]: what changed, the commit, which tests ran.
3. Decisions go in [[Decisions and Open Questions]]. Canonical decision records stay in the repo's `DECISIONS.md` / `DECISION_LOG.md`.
4. Trust git over this vault: before acting on a note, check the commit it points at.
